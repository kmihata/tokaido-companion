# Working traces

Drop GPX exports here while a tracing session is in progress. This folder is in
Dropbox, so anything saved here is off the machine within seconds.

**Export from the editor often.** Browser-based editors keep their state in the
browser; a crash, a refresh, or a stray navigation can take hours with it. An
exported GPX is a *save*, not a commit — load it back into gpx.studio later and
carry on drawing.

Name them so a wrong turn can be backed out of:

```
hakone-hybrid-v1.gpx
hakone-hybrid-v2.gpx
kyoto-approach-v1.gpx
```

When a section is finished, import it into Samwise (Route → Import geometry),
which records its filename and provenance. Files here are working copies and can
be deleted once the edit is adopted and exported — but there is no hurry.
